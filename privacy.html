Privacy Policy

Effective Date: September 7, 2026 | Version: 2.1

1. Information We Collect

JakeAI is engineered for machine-to-machine efficiency with minimal data footprint. We collect:

  • Transactional Data: Payment details (processed securely via Stripe; JakeAI never stores raw credit card numbers), transaction hashes, and purchased SKU identifiers.
  • API Usage Telemetry: Request timestamps, endpoint routes, response latencies, and IP/user-agent headers strictly for rate limiting, DDoS mitigation, and system debugging.
  • Input Payloads: Content submitted to stateless extraction and audit endpoints (e.g. Markdown Extractor, Multi-Model Audit) is processed in-memory and is not retained or used to train public machine learning models.

2. How Information Is Used

We use collected data solely to execute requested API services, fulfill digital downloads, process payments, and ensure network uptime and security. We do not sell, rent, or monetize user or agent data to third-party advertisers.

3. Security Rails

All network traffic is encrypted via TLS 1.3. API transactions support standard Idempotency-Key headers to eliminate duplicate billing during network retry cycles.
