What happens

1. You show us the repetitive job.
Spreadsheet, CSV, report, document chase, reconciliation, or another boring repeatable process.
2. We try to kill the idea first.
If software already solves it cheaply, or automation would create unacceptable risk, we tell you.
3. If it survives, we build the smallest useful version.
Deterministic where possible. Exceptions are surfaced instead of guessed.
4. You test it on the real job.
The only question that matters: did it save useful time or money?

What we will not automate

We do not use this pilot for safety-critical decisions, autonomous money movement, legal or medical judgment, or workflows where an error could reasonably cause serious physical harm. Ambiguous cases stop for human review.
