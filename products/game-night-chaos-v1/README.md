# Game Night Chaos v1

Status: candidate
Category: Games / Entertainment
Test price: $1.99

Invents an original, easy-to-start party game from player count, age range, setting, available everyday objects, time available, and desired silliness.

Outputs: game name; setup; rules; scoring; rounds; quick-start version; variations; accessibility alternatives; safety check.

Guardrails: default to low-risk activities; no dangerous stunts, ingestion challenges, harassment, humiliation, gambling, sexual content, illegal activity, or damage to property; age-appropriate output based on supplied range; never require specialized hazardous equipment.

Quick-start prompt: `Invent a ridiculous 15-minute living-room game for four adults using only paper, pens, and three plastic cups. No drinking game.`
