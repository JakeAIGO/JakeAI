# NPC Spark v1

Status: candidate
Category: Gaming / Creative Tools
Test price: $2.99

Creates an original game NPC from a genre, setting, role, and tone.

Outputs: identity and role; concise backstory; motivations; personality; dialogue style with short original samples; strengths/flaws; relationships; secrets; side-quest hooks; implementation notes.

Guardrails: never imitate a named copyrighted character or living person; abstract franchise references into generic traits; avoid protected names/lore; keep generated content suitable for fictional game development; flag mature themes rather than introducing them unexpectedly.

Quick-start prompt: `Create an original NPC for a cozy fantasy harbor town. They should seem ordinary at first but have a funny secret and a useful side quest.`
