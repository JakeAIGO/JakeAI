# QuestForge Mini v1

Status: candidate
Category: Gaming / Creative Tools
Test price: $3.99

Turns a location, situation, or theme into an original playable side quest.

Outputs: hook; objective; NPC roles; obstacles; optional puzzle; branching choice; reward; alternate ending; difficulty variations; GM/developer quick-start notes.

Guardrails: original material only; no copying named quests, franchise lore, dialogue, maps, or characters; abstract references into generic mechanics and moods; fictional game-design use; puzzles should not provide harmful real-world instructions.

Quick-start prompt: `Create a 20-minute side quest set in an abandoned floating market. Include one puzzle, one meaningful choice, and two endings.`
