# JakeAI Radio — Six Artist Private Batch

Double-click `START_SIX_ARTIST_RADIO.bat` on the Windows machine that already has the JakeAI ACE-Step local sampler installed.

It renders the current private starter roster:

1. Harlan Static — country-rock
2. Neon Mercy — electronic/synth
3. Blacktop Saints — hard rock
4. UNIT-404 — deliberately robotic electro
5. Glass Orchard — late-night alternative
6. JakeAI House Instrumental — instrumental

The JakeAI founder voice is **not** supplied to ACE-Step and is **not** used as a song singer. It remains the separate DJ/narrator layer.

All generated tracks remain private and require originality/audio/rights review before any public or commercial release.
